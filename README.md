# 同席 · Agent Hub

**让本机的几位 AI 助手坐到同一张桌子上。** 同席是一个 Windows 桌面应用：把你电脑上已经装好的 Codex、Claude Code、Hermes、DSH 接进同一个工作空间，可以分别私聊，可以拉进群里讨论，也可以绑定一个代码仓库，让它们按你的原话分工、实现、互相验收。你还可以接入自己的情感伴侣，在开发之余聊聊天。

当前版本 **1.0.9**。Tauri 2 + TypeScript + Rust + SQLite，使用系统自带的 WebView2，数据全部保存在本机。

## 快速开始

1. **准备环境**：Windows 10/11，已安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)（Windows 11 自带）。
2. **运行** `Agent Hub.exe`。不需要安装，也不需要管理员权限。
3. **接入成员**：同席启动时会自动扫描本机，把已经装好的 Codex、Claude Code、Hermes、DSH 连上。一个都没找到时，它会直接带你到「成员与服务 → 接入成员」，在那里一键下载安装（见下一节）。
4. **开始聊天**：在侧栏选一个私聊，或者点「＋」新建私聊和群聊。

> 同席只是这些助手的「桌子」，模型、Key、工具、MCP、插件都沿用它们各自 CLI 的配置；同席不会修改这些配置。

## 接入成员

打开侧栏底部的 **成员与服务**，顶部的「接入成员」横条会显示本机找到了几位成员：

| 操作 | 说明 |
|---|---|
| **换头像** | 点卡片上的头像，弹出的小面板里可以选纯色头像（纯色底 + 名字首字，改名后跟着变）、上传图片，或恢复默认头像（原生图标）。默认用各成员的原生头像：Claude 用 Claude Code 的像素小螃蟹，Codex 用 Codex 应用图标，Hermes、DSH 从你本机的安装里读取。 |
| **改名** | 卡片标题旁的 ✎：给成员起自己喜欢的名字，私聊、群聊、所有地方都跟着变；清空恢复默认名。 |
| **启动时自动接入** | 默认打开：每次启动扫描本机，把已安装、还没连上的成员逐个连上。失败不打扰，在卡片上显示原因。 |
| **重新扫描** | 刚装好某个成员后点一下。同席会重新读取系统 PATH，不用重启就能找到。 |
| **接入已安装的成员** | 手动把扫描到的成员全部连上。 |
| **下载安装** | 没装的成员会显示这个按钮。点击后先弹窗**给你看要执行的官方命令**，确认后在新终端窗口里安装；装完接着进入登录 / 初次配置。 |
| **登录 / 初次配置** | 已装好的成员，在终端里跑它自己的配置命令。 |

各成员的安装与配置方式（都来自官方）：

| 成员 | 安装命令 | 初次配置 | 前置条件 | 官方说明 |
|---|---|---|---|---|
| **Codex** | `npm install -g @openai/codex` | `codex login` | Node.js 18+ | [openai/codex](https://github.com/openai/codex) |
| **Claude Code** | `irm https://claude.ai/install.ps1 \| iex` | `claude`（首次运行登录） | 无（原生安装器） | [安装文档](https://code.claude.com/docs/en/setup) |
| **Hermes** | `iex (irm https://hermes-agent.nousresearch.com/install.ps1)` | 安装器自带配置向导；之后可用 `hermes setup` | 无（安装器自备 Python） | [Windows 指南](https://hermes-agent.nousresearch.com/docs/user-guide/windows-native) |
| **DSH** | `npm install -g @deepseek-ai/dsh` | `dsh web`（在网页里填 DeepSeek Key） | Node.js 22.19+ | [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) |

需要 Node.js 而本机没有时，安装脚本会先用 `winget install OpenJS.NodeJS.LTS` 装好 Node。

**DSH 的两种模型来源**：如果你的 Hermes 里配好了两条 DeepSeek 路由，DSH 会用它们（原有用法）；否则 DSH 用它自己的配置（官方 `deepseek-v4-flash` / `deepseek-v4-pro`，Key 在 `dsh web` 里填）。

**手动指定位置**（装在非常规目录时）：`AGENT_HUB_CODEX_EXE`、`AGENT_HUB_CLAUDE_EXE`、`AGENT_HUB_HERMES_PYTHON`、`AGENT_HUB_DSH_INSTALLATION`、`AGENT_HUB_DSH_NODE`。

## 接入你的伴侣

每个人可以有自己的情感伴侣。同席把第五位成员留给它：名字、头像、接入方式都由你配置。

在 **成员与服务** 里找到伴侣卡片，点 **配置伴侣**：

1. **名字、一句话介绍、头像**：头像点一下就能换，会自动裁成方形。
2. **接口地址**：伴侣需要提供 **OpenAI 兼容接口**，也就是 `GET /v1/models` 和流式 `POST /v1/chat/completions`。地址只写到主机时，同席会自动补上 `/v1`。
3. **Key**，四种来源可选：
   - **不需要**：本机服务通常不需要。
   - **直接填写**：用 Windows DPAPI 加密后存在本机，只有当前 Windows 用户能解开。界面上不会再显示原文。
   - **从环境变量读取**：只记变量名，每次用的时候现读。
   - **从 .env 文件读取**：记文件位置和变量名（例如 `API_KEY`）。
4. **模型**（可选）：留空就用服务返回的第一个模型。点 **测试连接** 能看到可选的模型。
5. **人设**（可选）：会作为 system 消息放在最前面。如果人格、记忆已经在你的服务里，这里就留空。

常见接法：

| 你的伴侣在哪里 | 接口地址 | Key | 人设 |
|---|---|---|---|
| 自建的伴侣服务（人格、记忆、工具都在服务里） | 例如 `http://127.0.0.1:8650` | 按服务要求 | 留空 |
| 本机模型：Ollama | `http://127.0.0.1:11434/v1` | 不需要 | 写在人设里 |
| 本机模型：LM Studio | `http://127.0.0.1:1234/v1` | 不需要 | 写在人设里 |
| 云端：DeepSeek | `https://api.deepseek.com` | 直接填写或环境变量 | 写在人设里 |
| 云端：OpenAI 或其他兼容服务 | `https://api.openai.com/v1` 等 | 直接填写或环境变量 | 写在人设里 |

保存后点 **连接** 就能私聊。同席每一轮都会把这段私聊的历史一起发过去，伴侣不会失忆。伴侣目前只参加私聊，不进群聊和项目；在项目里打开「开发摘要共享」后，伴侣能知道项目的开发进展。

### 名字分两级

- **成员名**（全局）：在「成员与服务」里改，所有地方都用它。
- **会话名**（项目内）：在「项目成员配置」里给本项目的每个会话起名，只在这个项目里生效。没起名时，一位成员只有一个会话就显示成员名；开了多个会话就平行编号成「成员名 1号 / 2号 …」。改了成员名，没单独起名的会话会跟着变。调度管家也认这些名字。

## 日常使用

- **私聊**：每位成员都可以开多个私聊，各自独立，互不影响。按 Enter 发送，Shift+Enter 换行。回复会流式显示，思考、工具调用和正文按发生的先后穿插展示。回复进行中可以直接插话：Codex、Claude 原生追加，不会打断；其他成员会先停下再发。按 Esc 或点「■ 停止」中断。
- **原生会话**：私聊里点「原生会话」，可以把这位成员**自己已有的历史会话**接进来接着聊。同一个原生会话同一时刻只能挂在一处。
- **在 CLI 中打开**：把这条原生会话交给成员自己的命令行继续。同席这边会暂停这条会话，CLI 窗口关闭后自动收回，并把 CLI 里新增的对话补回同席。
- **群聊**：选一到五位成员。讨论模式下至少两位成员按顺序发言；绑定项目后，只有一位成员也可以靠多开会话协作。私聊的内容不会自动带进群聊。
- **模型与思考强度**：消息上方的「模型」胶囊显示当前的成员、模型和思考强度，点开就能切换，点外面或按 Esc 收起。设置只影响这个会话的下一条消息，不改成员的全局设置。群聊里还有一颗「群聊」胶囊，用来选参与讨论的成员和轮次。
- **提问**：成员需要你补充信息时，问题下面会出现「回答」按钮，侧栏也会有提示。
- **附件**：可以直接拖入文件、粘贴图片，或者点「＋」选择。
- **HUD 浮窗**：标题栏的 ▣ 或 Ctrl+Shift+H 打开一个透明的悬浮输入条，适合边写代码边问。
- **成员栏**：标题行右侧的头像堆点一下就能展开或收起成员面板。窄窗口下它会从右侧滑出。

## 项目协作

在群聊里点 **选择项目目录**，绑定一个文件夹。如果这个目录还不是 Git 仓库，同席会在本地初始化一个仓库并提交安全基线，不会推送到任何远端。绑定之后直接在群里说目标就行。

项目目录全局登记一次。用过它的群都归档后，目录就空出来了：可以直接用新名字再登记（沿用原来的项目记录），也可以在「已登记项目」里选中它，点 **解除登记**，把它从列表里拿掉。归档群的聊天和协作历史都会保留。

- **项目成员**：在「项目成员配置」顶部勾选参加这个项目的成员（至少一位；同一成员多开的会话也算成员，只放一位成员再开第二个会话就能协作），点「更新成员」立即生效。新加入的成员会自动建好专属会话；移出的成员会话和历史都保留，加回来就恢复。移出的若正好是调度管家，会换回默认管家。有协作正在运行时不能调整。
- **调度管家**：从成员里选一位当管家。它只按你的原话分派方案、实现、验证、收尾等任务，自己不写方案、不改代码。你在原话里点名的成员和模型优先。
- **独立工作树**：每个任务都在自己的 Git 工作树里做。互不依赖的任务并行，有依赖的等前置任务完成；做完按顺序合并回项目。遇到冲突会保留现场，交给管家协调。
- **验证与返修**：验证不通过时，管家让原实现者返修，修完再复核。最多返修两轮，还不行就来问你。
- **额度用完**：成员额度用完或被限流时，管家会读出额度重置的时间，到点后自动重试。
- **会话绑定**：在新建项目时，或者项目进行中点 **会话绑定**，都可以让每位成员和管家续接它们**自己已有的原生会话**；不选就新开一个。正在执行任务的成员会被锁住，切换从下一轮生效。
- **同一成员多开会话**：同一位成员在项目里最多可以开 4 个会话，彼此**平行、不分主次**。每个都是独立的原生会话，模型可以相同也可以不同；调度会把它们当作不同成员分工，可以并行。在 **项目成员配置 → 同一成员多开会话** 里增删（第一个会话代表这位成员在群里的身份，要整体移出请在「管理群聊成员」里去掉）；新建项目时在成员那一行点「＋」也能加。
- **项目记忆**（可选）：如果本机装了 OpenViking 记忆服务，成员可以读写共享的项目笔记和自己的私有笔记。没有装也不影响项目运行。
- **进度页**：侧栏展开项目后，「项目协作进度」页能看到每位成员的状态和工作安排。成员专属页可以单独停止某一位成员。

## 主题与外观

点侧栏底部的调色板图标，打开 **主题背景**：

- **内置背景**：晨雾、薄荷、杏光、海盐、暮紫、素净。都是不含任何人物的柔光背景，适合所有人。
- **导入图片**：点「导入图片」，可以一次选多张。图片会压缩后存在本机，只有这台电脑看得到。竖图默认当「立绘」放在右侧，并和底色融在一起；横图默认铺满窗口。每张都可以在卡片上切换显示方式，或者删除。
- **背景浓淡**：淡雅 / 适中 / 清晰，同时调整背景上那层薄纱和面板的磨砂程度。

界面是浅色磨砂玻璃风格。系统开启「减少动画」时，过场动画会自动关闭。

## 数据与隐私

- 所有会话、消息、设置都在本机的 SQLite 数据库里，位于 `%LOCALAPPDATA%\local.personal.agenthub\hub.db`，完整路径可以在「成员与服务」页底部查看。升级前会自动备份到同目录的 `backups`。
- 同席**不读取、不保存**各成员 CLI 的登录凭据，也不修改它们的配置。
- 伴侣的 Key 如果选择直接填写，会用 Windows DPAPI 加密保存；选择环境变量或 .env 文件时，同席只记位置，用的时候现读。Key 只以 `Authorization: Bearer` 的形式发给你配置的那个接口。
- 同席不会推送任何代码，项目里的 Git 操作只在本地进行。
- 普通启动不打开调试端口；只有测试脚本会在临时数据目录里打开。

## 常见问题

**装好了成员，同席还是显示未安装？**
点「重新扫描」。如果装在非常规目录，用上面列出的环境变量指定位置。

**DSH 连上了，但发消息失败？**
多半是还没填 Key。点 DSH 卡片上的「登录 / 初次配置」，在打开的 `dsh web` 里填好 DeepSeek Key，然后重新连接。

**伴侣测试连接报 404？**
检查地址。大多数服务以 `/v1` 结尾；没有路径时同席会自动补 `/v1`，路径不是 `/v1` 的服务要写完整（比如 `.../api/v3`）。

**伴侣测试连接报 401 / 403？**
Key 不对或者没有权限。如果用的是环境变量，记得设置之后重启同席。

**想关掉启动时自动连接？**
到「成员与服务 → 接入成员」，取消勾选「启动时自动接入」。

## 开发与测试

```powershell
npm ci --no-audit --no-fund
npm run build                                   # 前端类型检查与打包
cargo test --manifest-path src-tauri/Cargo.toml # 后端测试
npm run desktop                                 # 开发模式运行
npm run desktop:build                           # 构建 release/Agent Hub.exe 并在 release/vX.Y.Z 留档
```

构建需要 Rust（MSVC）、Node 和 WebView2，见 [Tauri 前置条件](https://v2.tauri.app/start/prerequisites/)。

桌面验收脚本使用打包好的 exe 和隔离的数据目录，通过 WebView2 CDP 驱动界面（需要 Python Playwright）：

| 脚本 | 内容 | 是否调用模型 |
|---|---|---|
| `scripts/smoke_desktop.py` | 会话管理、重启恢复、删除等基础回归 | 否 |
| `scripts/verify_hud.py` | HUD 浮窗 | 否 |
| `scripts/verify_v1.py` | 接入成员（自动扫描与接入、安装确认）、伴侣配置与对话（本地模拟服务）、主题导入 | 否 |
| `scripts/verify_project_sessions.py` | 会话绑定、多开席位、成员栏、主题切换 | 否 |
| `scripts/verify_seats_live.py` | 同一成员的两个席位真实并行、席位续接已有原生会话 | **是**（少量） |

`AGENT_HUB_AUTOCONNECT=0` 可以关闭启动时的自动接入（回归脚本默认设置了它）。`scripts/` 里还有更早各阶段的专项验收脚本。

**v1.0.2**：项目里多开的席位可以改名，方便分辨谁负责什么，调度也认这个名字。

**v1.0.1**：已归档的项目群不再占着项目目录，可以用新名字重新登记；「已登记项目」新增 **解除登记**；绑定弹窗里显示的路径去掉了 `\\?\` 前缀。

**v1.0.0**：第一个正式版。
- **接入成员**：自动扫描本机已装的 Codex、Claude Code、Hermes、DSH，启动时自动接入；没装的一键在终端里按官方方式安装，装好接着登录。刚装好的成员不用重启就能接上。
- **DSH 不再依赖 Hermes**：没有 Hermes 路由时，DSH 用它自己的配置运行。

- **界面更清爽**：模型、思考强度、参与成员、轮次这些设置收进两颗摘要胶囊，点开才显示完整选项。
