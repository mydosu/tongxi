# 更新日志

安装包在 [Releases](https://github.com/mydosu/tongxi/releases)。「主脑」是 Leader 的旧称，说的是同一个角色。

- **v3.9.6**（2026-11-24）：修项目成员面板：权限档、其他项目的需求、每日花费上限和成员勾选散成竖排的恢复成一行一项，去掉底部的横向滚动条，「再开一个会话」的名字框不再被挤扁。「成员与服务」里默认工作文件夹的示例路径补回反斜杠，几处 Leader 称呼前后的空格放对。README 和上手教程按现在的界面重写。
- **v3.9.5**（2026-11-24）：派活页的计划、待机、项目往来、用量、总账、计划与任务书都能收起，并记住收起状态；结束了的任务、待机、往来一行一件，更早的收成一条，可以单删也可以全删（任务书挪到 `.tongxi/已删除/`，往来两边一起删；删任务只是不再列出，用量、成员成绩、工作树照旧）。在派活页暂停、继续、现在跑、删除待机，以及这些删除，都不再发消息叫醒主脑，省额度；检查命令还在跑时删掉或暂停的待机，这一次也不再叫醒。顺带修状态标签被挤成竖排。
- **v3.9.4**（2026-11-21）：修 Antigravity 跑长时间的后台命令（长计算、并行测试）时被误判卡住：这类命令跑完前 agy 一行都不输出，后面的步骤也压着不发，同席 30 分钟没动静就把长任务掐断了。现在有工具还没结束时每分钟报一次平安，没有工具在跑时照旧判卡住。
- **v3.9.3**（2026-11-20）：主脑给不支持插话的成员（DSH、Hermes 等）插话时，同席自动先停下再在同一会话里接着发，缓存还热，活跟到新那轮再交回；主脑自己停下成员的活当场收尾、不再另有交回，停稳了才返回，接着就能重新派。之前插一次话要来回叫醒主脑三轮。
- **v3.9.2**（2026-11-18）：主脑的待机挂上或改了检查命令时，同席当场跑一次、把输出直接回给主脑看，没有输出会点明。原来第一次的输出只是悄悄记下，命令没对上（比如 gh run list --commit 写了短 SHA，什么都不打印）每次都一样，CI 早就出结果了主脑还一直等不到。
- **v3.9.1**（2026-11-18）：修好主脑的待机不叫醒：带检查命令的待机原来用系统自带的 Windows PowerShell 5.1 跑，调用 gh 这类程序时参数里的双引号会被吞掉，命令每次报同样的错、被当成「没变化」，主脑一直等不到。现在装了 PowerShell 7（pwsh）就用它跑；检查命令第一次就报错时，会把输出给主脑看一次，写错了能马上改。
- **v3.9.0**（2026-11-17）：主脑可以挂「待机」了：到点提醒、定时巡检，或每隔几分钟在项目目录跑一条命令、输出变了才叫醒它，例行查看还能交给便宜成员、没新情况就不打扰主脑；同席关着时错过的开机后补一次，额度快见底会自动往后推。项目之间可以互提需求：一个项目的主脑请另一个项目的主脑做事，做完把结论和文件交回、文件复制进发起方项目的 .tongxi/收件，项目设置里可选直接接、先问我或不接。两者都在派活页有新栏目，可暂停、删除、停掉。计划流程图改成横平竖直的走线，步骤多时不再缠成一团。成员自更新的兜底时间放宽到 30 分钟，Hermes 装依赖时不再被半路停掉。
- **v3.8.29**（2026-11-13）：成员的工作树不再放在 C 盘的同席数据目录里，改放在项目旁边的`<目录名>-worktrees`，跟项目同盘、按项目分开；选空文件夹新建项目时，同席在里面建`<文件夹名>-main`当主仓库、工作树放在同一层的`<文件夹名>-worktrees`，再选这个外层文件夹会认回里面的主仓库。已有的工作树照旧可用。
- **v3.8.28**（2026-11-13）：成员放到后台的任务跑完不再通知 Leader（以前频繁打扰）；结果先存着，下次给这位成员派活时附在任务前面，由成员自己看。
- **v3.8.27**（2026-11-13）：模型选择按会话生效：Claude 上一轮留着后台命令时中途换模型或思考强度，下一条消息起就生效（以前沿用旧进程的模型）；在 Leader 会话里换模型，项目设置和以后新开的 Leader 会话都跟着它；项目设置里 Leader 模型选「沿用」不再把 Leader 会话清成默认模型。
- **v3.8.26**（2026-11-13）：修项目群换绑项目后新开的 Leader 会话没用上项目设置里选的主脑模型（比如选了 Fable，实际一直跑成员上次用的 Sonnet）：新开的 Leader 会话现在会按项目设置同步一次模型和思考强度。
- **v3.8.25**（2026-11-12）：手机打开同席时先试连电脑：没开 Tailscale 或电脑上的同席没开，会提示「连不上电脑」并每 3 秒自动重试，连上自动进入，不再落到系统错误页；用着时和电脑断开超过 3 秒，顶部显示「电脑离线，正在重连…」。本版起 Release 重新附带安卓安装包。
- **v3.8.24**（2026-11-11）：修 Claude 的回复时不时断在半截：回复快写完时你插话（或成员交回刚好到达），Claude 会另起一轮接着处理，同席却按前一轮收尾、20 秒后结束进程，后面的内容丢失，界面还显示成已完成。Leader 最容易遇到。
- **v3.8.23**（2026-11-10）：修项目群换绑到另一个项目（比如项目目录改名后重新登记）之后，Leader 派活和成员交回仍落到旧项目那套会话：派活直接失败或界面上看不到输出，Leader 也收不到交回。
- **v3.8.22**（2026-11-10）：修项目设置里主脑「称呼」输入框样式简陋、与旁边下拉框对不齐。
- **v3.8.21**（2026-11-09）：「主脑」的称呼可以改了，默认叫 Leader：在项目群成员面板「Leader」一栏的「称呼」里改，所有项目通用，清空恢复默认（给成员的提示词和派活消息格式不变）；README 演示视频给无关会话打了码。
