# 开发者版路线图

对象：已经在用 Claude Code、Codex、Hermes、DSH 这些 CLI 的开发者。要回答他们的一个问题：为什么不直接开几个终端，而要用同席。答案靠三件事：敢交权、看得见省钱、跟得上 CLI 升级。

## 第一版：v3.4 敢用、看得见省钱

### 1. 省钱账（先做）
- **用量记全**：现在 Claude、DSH 每回合有用量；Hermes 几乎全空，Codex 只有一小部分有。先把这两家补齐，账才算得准。
- **价格表**：找回 v1.1.1 的价格表——每天从 LiteLLM 社区价格表自动更新，联网不上用内置表兜底（含分段价、闲时价、缓存写价）。
  - 没有价格的模型显示「价格未知」，不瞎估。
  - 订阅线路（Claude、ChatGPT 账号）也按 API 价折算，标明「按 API 价折算」。
- **一件事一行账**：派活页每件事、每个计划步骤都显示这几样：
  - 各成员用了多少 token、折合多少钱；
  - 如果全程交给主脑那个模型做要多少钱、省了多少。
- **项目总账**：项目设置里按天、按成员、按模型汇总。

### 2. 花费上限
- 每个项目可以设「每天最多花多少」（只算按 token 计费的线路）。到额度就不再派新活，在问答面板告诉用户。
- 已经在跑的活不掐，做完再停。

### 3. 权限档
- 每个项目选一档：只读 / 只改工作树（默认）/ 全权。
- 成员启动参数按档位来（Claude `--permission-mode`，Codex `sandbox`、`approvalPolicy`），不再写死全开。
- 合并工作树、推送、部署这类收不回的操作，不在授权里的先挂到问答面板等用户点头；合并前给看 diff。

### 4. 自我更新
- 接上 Tauri updater，启动时查 GitHub Release，有新版就提示一键更新。
- 发版流程顺带生成更新清单并签名。

## 第二版：v3.5 能接更多 agent

### 5. 自定义 ACP 成员
- 填命令和参数，就能把任何讲 ACP 的 agent（Gemini CLI、opencode 等）接成成员，不用为每家写代码。

### 6. 项目记忆可降级
- 没装 OpenViking 时，项目记忆退回到项目里 `.tongxi/记忆/` 下的 markdown；装了再用 OpenViking。
- 去掉写死的本机默认路径。

### 7. 诊断
- 「导出诊断」一键打包脱敏日志、各家 CLI 版本、连接状态。
- 维护一张已验证的 CLI 版本表，用户装的版本不在表里就提示可能不稳。

## 第三版：v4.0 macOS
- 进程管理（Job Object）、`cfg(windows)` 那 27 处、WSL 那条线换成跨平台实现，出 macOS 包。

## 以后再说：差异化方向（2026-10-24 讨论，未排期）

同类多 agent 协作项目已经很多（AionUi、Orkas、agent-orchestrator、paperclip 等），核实后：
- 省钱账不算独有：paperclip 有预算和花费追踪，agenthub 有省钱统计和按额度换号。只剩「对比全交给主脑模型」这种算法还算领先。
- 轻量不算独有：awesome-agent-orchestrators 的 281 个项目里有十几个 Tauri 或单文件程序，但同时满足 Windows 原生、有图形界面、8 MB 免安装的很少，可以当加分项。
- 二次元角色是唯一空白：281 个里一个都没有。

定位：轻、好看、带上你自己的角色，省钱放在后面当实际好处来讲。同席不带角色（没有原创角色，官方立绘也不进包），用户带自己的；阿尔比恩做 README 演示。

按用户手里有什么分档，每档都不依赖上一档：
1. 什么都没有：活做完了、失败了、等确认时弹 Windows 系统通知（现在只有窗口内角标）。
2. 一张角色图：导入「角色包」，包含主题立绘、通知头像和台词模板；不需要模型，也不多起进程。大多数人停在这档。
3. 一个 API Key：提醒交给陪伴座位，按人设现编一句话。
4. 一个桌宠：连 AIRI channel-server（`ws://127.0.0.1:6121`），发 `spark:notify`。阿尔比恩的外壳（`D:\AI\Wife\shell`）保留了这个服务，上游 AIRI（约 5 万星）也能用；对应 AIRI issue #2507 的 Agent Activity 插件。

待定：轻量桌面小人（透明置顶窗口，显示立绘和对话气泡）；英文界面。
未核实：外壳收到 `spark:notify` 后，是交给她的 Pi 脑生成反应，还是走外壳自己的模型；Tauri 通知插件能不能显示自定义头像。
