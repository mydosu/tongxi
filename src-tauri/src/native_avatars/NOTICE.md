# 成员原生头像

- `claudecode-color.svg`：Claude Code 的像素小螃蟹 Clawd，来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 1.95.1，MIT 许可）。
- `codex-color.svg`：Codex 应用图标，来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 1.95.1，MIT 许可）；OpenAI 没有公开的 Codex 图标下载。
- `antigravity-color.svg`：Antigravity 的彩色拱门标，来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 1.101.0，MIT 许可）。
- `opencode.svg`：OpenCode 的方框标，来自 [LobeHub Icons](https://github.com/lobehub/lobe-icons)（`@lobehub/icons-static-svg` 1.101.0，MIT 许可）；原图是 `currentColor` 单色，这里写死成深灰 `#211e1e`，放在白底上才看得见。
- Hermes、DSH 的头像不打包，运行时从用户本机的安装里读取（Hermes 的 `assets/icon-master.svg`、DSH 网页端的 `favicon.svg`）。

这些标志的商标归各自所有者，同席只用它们标识对应的成员。
